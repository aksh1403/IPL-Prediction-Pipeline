🏏 IPL Win Prediction

A machine learning project to predict IPL match outcomes using historical IPL match and ball-by-ball data.

🔹 Current Progress

* Data cleaning and preprocessing
* Feature engineering
* Regression model
* Logistic Regression for match outcome classification
* Model evaluation

🛠️ Tech Stack

Python • Pandas • NumPy • Scikit-learn • Matplotlib • Seaborn
